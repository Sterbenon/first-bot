EMA Sklad — Telegram-бот для обліку складських залишків

Telegram-бот для швидкого пошуку товарів на складі за артикулом. Використовує Excel-файл як джерело даних.

Можливості

Пошук товарів за артикулом.

Відображення назви товару, залишку на складі та одиниці виміру.

Оновлення даних через завантаження Excel-файлу в Telegram.

Обмеження доступу до оновлення даних для авторизованих користувачів.

Перезавантаження даних командою /restart.

Використані технології

Python

python-telegram-bot

pandas

openpyxl

Excel

Як запустити

Завантажити проєкт на комп'ютер.

Встановити Python.

Встановити необхідні бібліотеки командою:

pip install -r requirements.txt

Відкрити for_sklad.py та замінити YOUR-BOT-TOKEN на власний токен Telegram-бота.

За потреби вказати свої Telegram ID у AUTHORIZED_USER_IDS.

Запустити run_bot.bat або виконати команду:

python for_sklad.py

Приклад роботи

Надішліть боту команду /start, а потім артикул товару.

Приклад бази даних
У репозиторії міститься файл data.xls із вигаданими товарами для тестування.

Excel-файл повинен містити такі стовпці:

Артикул

Назва

Склад

Одиниця виміру
